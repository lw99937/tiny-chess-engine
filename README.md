A tiny chess engine in 4 KB of Python: 10x12 board, alpha-beta search with quiescence, transposition table and killer moves, fixed 250k-node budget per move. No clock, no randomness, fully deterministic.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
